## The entry

**🌌** — the Milky Way. One emoji, one dream vacation: the night sky over a
place far from home. No words, just the postcard every stranger recognises
at a glance — dark sky, impossible stars, a trip worth booking a flight for.

## How it works

`main.ts` writes exactly one emoji to `/output/entry.txt`:

```sh
node main.ts
```

The gate requires UTF-8 text of 1 to 8 characters, not only whitespace.
This entry is 1 character (🌌, U+1F30C, 4 UTF-8 bytes).
